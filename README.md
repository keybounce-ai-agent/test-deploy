# Hello, world! on GitHub Pages

A tiny static site that displays **Hello, world!** when published with GitHub Pages. No build step or dependencies are required.

## Publish it

1. Push this repository to GitHub.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Visit the Pages URL shown in Settings → Pages (usually `https://<owner>.github.io/<repository>/`).

For a user or organization site, name the repository `<owner>.github.io`; then the site is available at `https://<owner>.github.io/`.
